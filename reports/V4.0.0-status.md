- **Upstream source format (plan section 8, item 1).** `Instrument/instrument-sans` has `sources/InstrumentSans.glyphs`, `sources/InstrumentSans-Italic.glyphs` and `sources/config.yaml`. The Stage 2 route is therefore Glyphs sources through glyphsLib and fontmake; extracting UFOs from TTFs is not needed.

Upstream lists only aalt, case, liga, pnum and tnum besides ss01-ss12, so the thin number features are inherited.
- **Environment.** fontTools 4.67.0 is available; brotli, fontbakery, gftools and fontmake are not; there is no network.
