What the research found

Pinterest Sans was designed by Grilli Type with Made Thought in 2021, with a tall x-height. Pinterest’s public Gestalt docs say product UI uses system fonts, which conflicts with the screenshots: the UI digits do not match the phone’s status-bar font. Which face the app ships is unconfirmed, and pinterest.com blocks automated inspection.
